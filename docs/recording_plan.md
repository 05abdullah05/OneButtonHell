# Recording + hand-in plan (all due 31/10)

## Before recording
- Export the final build: Project → Export → Windows Desktop → Export Project (Embed PCK on, debug off).
- In the game: Levels → Reset Progress (press twice) so the playthrough starts clean.
- Record from the exported .exe, not the editor (no debug toolbar). Close notifications.
- OBS: Settings → Video 1920x1080, 60 FPS. Source "Window Capture" of the game + "Audio Output Capture".
  For the individual screencast add "Video Capture Device" (webcam), shrink it to a corner = PIP, plus your microphone.

## 1. Playthrough (no commentary): record first, it is the easiest
- Main menu → Start → play levels 1 to 7 in order, every level to the end.
- Show the pause menu once and the level complete screen after each level.
- Deaths are fine, but don't cut whole levels: the course judges what is in this video.
- Try to collect coins on risky routes at least once (shows the skill element).
- End on "YOU BEAT THE GAME!", then briefly the Levels page with best coins.
- Upload to YouTube (Public or Unlisted, as the course requires).

## 2. Teaser (30-60 s): cut from your best clips
Action from the first second, no long intro. Suggested order:
1. 0-3 s: title in level 1 with the character running and jumping.
2. 3-15 s: quick cuts: spike jump, coin sparkle, death burst + shake, double jump with feathers.
3. 15-30 s: speed pads (cyan streaks), moving planks, crumbling bridge.
4. 30-45 s: the turnaround tower climb at night.
5. 45-55 s: goal confetti + "YOU BEAT THE GAME!", then title card: One Button Hell, "One button. Every jump counts."
Keep the game music as the soundtrack. Free editors: Clipchamp (Windows), DaVinci Resolve.

## 3. Individual development screencast (5-15 min)
- Follow docs/screencast_script.md. Do one practice run first.
- Webcam in a corner, microphone on. Show Godot, code and the running game.
